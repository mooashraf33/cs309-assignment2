About This Project

This educational project uses plain HTML and CSS to demonstrate a small, responsive website.

Project Goals

Semantic Structure

Build pages with meaningful HTML elements.

Responsive Layout

Use CSS Grid for phone, tablet, and desktop layouts.

Shared Styles

Keep the site design in one CSS file.

Accessible Forms

Use labels and fieldsets to describe form controls.

Color Contrast

Choose readable colors for light and dark modes.

Simple Examples

Show common components without extra complexity.
